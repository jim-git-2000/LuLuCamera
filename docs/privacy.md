# 数据处理说明（内测草案）

普通相机预览、人物姿态识别、即时噜噜合成、拍照和相册保存均在设备上完成，不因打开相机或普通拍照自动上传。

只有用户首次点击“生成高清噜噜”并确认说明后，客户端才上传原图、即时参考、编辑掩码、人物姿态和角色选择。服务用随机安装会话凭证隔离任务，默认 24 小时后清理服务端文件；客户端原图、即时图和高清结果保存在应用私有目录，默认 7 天后清理，用户主动保存的相册副本不由应用自动删除。

日志不得记录照片内容、会话令牌或供应商密钥。内测只收集自愿反馈和必要的本地操作结果，不收集原始相机画面，也不建立账号体系。正式分发前仍需根据实际部署主体、地区、供应商和保留策略完成法律与隐私审查。
