# 高清生成固定评测方案

当前仓库只建立评测契约，不包含用户照片、角色训练素材或模型权重。正式评测必须使用获得授权的固定输入，并记录其授权和 SHA-256；不得拿假生成适配器的输出作为质量结论。

评测集目标为 40 例，分层如下：

| 维度 | 分组 |
| --- | --- |
| 角色 | 噜噜 A 20 例、噜噜 B 20 例 |
| 人数 | 单人 24 例、双人 10 例、三人 6 例 |
| 动作 | 站立、抬臂/挥手、走动、轻微侧身 |
| 场景 | 室内/室外、简单/复杂背景、包含未选人物 |
| 风险 | 头发、伸手、人物靠近、编辑区重叠 |

每例保存原图、即时参考、逐人绑定元数据、编辑掩码和人工期望标签。输出记录模型 ID/修订、Diffusers 版本、输入/输出尺寸、seed、steps、显卡、峰值显存、排队/推理/总耗时和估算成本。

自动检查编辑区外逐像素相等；人工分别判定 A/B 身份、人物绑定、肢体、边缘、未选人物和背景。40 例中至少 36 例全部通过才达到计划中的 90% 门槛。先比较 Diffusers Inpainting 基线，再在同一集合验证兼容的 ControlNet 和 IP-Adapter；只有角色身份仍不稳定时才进入 LoRA 数据与训练评估。

当前阻塞项：正式 A/B 参考图与授权样例、GPU 环境和预算均未提供，因此尚无质量、显存、成本或时延数字。
