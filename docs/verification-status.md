## 本轮本地证据

使用已有 Python/Pillow/SQLite 做轻量检查，没有安装或升级开发环境：

- 19 个 Python 文件 AST、XML/JSON/YAML/TOML 解析与 Git 暂存/未暂存差异空白检查通过。
- PNG 缺失回退、透明 PNG 验证、自动选择参考图通过。
- 模拟逐人推理、IP-Adapter 按需加载与缺图权重回退、2 倍尺寸通过。
- 逐人实例图对框外旁人手臂和标签 255 的保护通过。
- 使用真实 Python 子进程（没有加载 GPU/模型）验证模型进程协议的复用、超时强制终止、下一任务恢复和取消通过。
- 之前的 SQLite 幂等/并发上限/恢复/取消和 Pillow 掩码外保护冒烟通过。

新增 CI 用例涵盖上述逻辑，以及肩线镜像反向、置信度掩码边界、像素点击和歧义交叉。本机无 pytest/FastAPI/Huey、Android SDK、Kotlin 编译器或 Docker，未执行完整 pytest、Android lint/test/APK、容器构建或真实 GPU 生成。语法和差异检查只作为轻量证据。

此前用户提供的 CI 日志已通过 AAR 与 Manifest 阶段，随后暴露 Kotlin 编译错误；旧修复在当前基线中，本轮改动仍需 CI 重新验证。下一步按 [使用准备](ready-to-use.md) 提供 PNG、准备 GPU 服务、设置 CI 地址并下载 APK 验收。发现真实编译、设备或模型问题后继续修复，不能把“代码写完”作为免验收依据。
