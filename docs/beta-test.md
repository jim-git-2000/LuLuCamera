# 小范围内测执行说明

内测只在 M2 候选经用户人工安装验收后开始。先安排 5 人无指导试用，修复阻碍拍照的问题后再扩至 20～50 人。由用户决定 APK 分发渠道和邀请方式，项目不会自动发布、部署或联系参与者。

参与者应完成：打开相机、选择人物、切换 A/B/真人、拍照、比较原图与即时图、保存一张照片；服务可用时再自愿尝试高清。观察者不先解释操作，只记录参与者是否自行找到入口。

每次记录：构建号、机型/系统、是否一次授权成功、入镜到可点选时间、是否正确选中人物、首次拍照和首次保存耗时、是否愿意保存、是否尝试高清、高清状态和失败码。只收集自愿反馈和操作结果，不收集原始相机画面，不为内测增加账号。

停止条件包括：保存失败率超过 1%、出现角色串人、编辑区外变化、照片上传未经过说明、崩溃/ANR 或参与者无法自主完成核心流程。先修复这些问题，再讨论分享、视频、遮挡、表情和更多角色。

反馈模板见 [beta-feedback-template.md](beta-feedback-template.md)。
