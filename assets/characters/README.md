# 角色图片入口

只在本目录放正式角色素材和授权说明，不放用户照片或生成结果。

- `lulu_a.png`、`lulu_b.png`：透明背景、完整角色，正面或轻微侧面；建议 512～2048 像素，四周尽量少留白。实时图是整体平移、缩放和倾斜，不包含分肢骨骼动画。
- `lulu_a_reference.png`、`lulu_b_reference.png`：可选的高清生成参考；未提供时直接使用同名实时 PNG，服务自动合成白底供 IP-Adapter 编码。
- 每个文件不超过 8 MiB / 4096 边长 / 8388608 像素。实时图必须有实际透明像素和非透明主体，CI 会检查；文件缺失时继续使用占位图。
- 可在此放 `LICENSE.md` 记录素材来源；不要伪造授权或放访问令牌。

补图后重新构建 APK，重启已有高清服务即可读取，无需改 Kotlin/Python。开发机器可用 `python3 scripts/check-assets.py` 检查；CI 会自动执行。高清仍需要可用服务主机及模型。带骨骼的 GLB 属于后续 3D 路线，PNG 不会自动变成 3D。
