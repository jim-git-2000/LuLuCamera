# LuLuCamera

面向 Android 的噜噜相机：点击画面中的人物，将其实时替换为噜噜水豚角色，拍照保存，并可在拍照后生成高清版本。

## 当前状态

已完成文档与版本管理准备，尚未进入开发阶段。当前没有 Android 工程、后端代码、角色资产、构建脚本或可安装 APK。

- [开发计划](PLAN.md)：产品范围、技术候选、12 个实施步骤与验收条件。
- [项目规范](AGENTS.md)：工作方式、开发环境约束与 Git 规则。

## 目录约定

按开发计划逐步创建目录，本次不建立空目录或占位工程。

| 路径 | 用途 |
| --- | --- |
| `android/` | Android 客户端与 Gradle 配置 |
| `backend/` | 拍后高清生成服务 |
| `assets/characters/` | 角色源文件、参考图与授权记录 |
| `docs/` | 架构、接口与验收记录 |
| `tests/fixtures/` | 获授权的固定测试素材 |
| `experiments/` | 技术验证，结论归档后清理中间产物 |
| `.github/workflows/` | 后续构建、检查和 APK artifact 工作流 |

以上为预定路径，尚未创建。细分目录与命名规则见开发计划第 4 节。

后续按“技术原型 M0 → 离线内测版 M1 → 完整 MVP M2”推进。技术栈与版本待原型实测后固化。
